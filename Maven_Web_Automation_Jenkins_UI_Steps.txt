MAVEN WEB APPLICATION AUTOMATION USING JENKINS FREESTYLE PROJECTS
===================================================================

STEP 1: OPEN JENKINS
--------------------
1. Open http://localhost:8080 in your browser.
2. Sign in to Jenkins.

STEP 2: CONFIGURE MAVEN
-----------------------
1. Click Manage Jenkins.
2. Click Tools (or Global Tool Configuration).
3. Find Maven installations.
4. Click Add Maven.
5. Enter the name: MAVEN_HOME
6. Select Install automatically, or configure the Maven installation path.
7. Click Save.

STEP 3: INSTALL REQUIRED PLUGINS
--------------------------------
1. Click Manage Jenkins.
2. Click Plugins.
3. Open Available plugins.
4. Search for and install:
   - Git plugin
   - Maven Integration plugin
   - Copy Artifact plugin
   - Build Pipeline plugin
   - Deploy to container plugin
5. Restart Jenkins if prompted.

STEP 4: CREATE MAVENWEB_BUILD
------------------------------
1. Return to the Jenkins Dashboard.
2. Click New Item.
3. Enter: MavenWeb_Build
4. Select Freestyle project.
5. Click OK.

CONFIGURE MAVENWEB_BUILD
~~~~~~~~~~~~~~~~~~~~~~~~
1. In the Description field, enter:
   Web Build demo

2. Under Source Code Management:
   a. Select Git.
   b. Enter the Git Maven Web application repository URL.
   c. Under Branches to build, enter the repository's branch:
      */main
      or
      */master

3. Under Build Steps:
   a. Click Add build step.
   b. Select Invoke top-level Maven targets.
   c. Select Maven version: MAVEN_HOME.
   d. Enter Goals: clean

   e. Click Add build step again.
   f. Select Invoke top-level Maven targets.
   g. Select Maven version: MAVEN_HOME.
   h. Enter Goals: install

4. Under Post-build Actions:
   a. Click Add post-build action.
   b. Select Archive the artifacts.
   c. Enter Files to archive:**/*

   d. Click Add post-build action again.
   e. Select Build other projects.
   f. Enter Projects to build:
      MavenWeb_Test
   g. Select Trigger only if build is stable.

5. Click Apply.
6. Click Save.

STEP 5: CREATE MAVENWEB_TEST
-----------------------------
1. Return to the Jenkins Dashboard.
2. Click New Item.
3. Enter: MavenWeb_Test
4. Select Freestyle project.
5. Click OK.

CONFIGURE MAVENWEB_TEST
~~~~~~~~~~~~~~~~~~~~~~~~
1. In the Description field, enter:
   Test demo

2. Under Build Environment:
   a. Select Delete workspace before build starts.

3. Under Build Steps:
   a. Click Add build step.
   b. Select Copy artifacts from another project.
   c. Enter Project name:
      MavenWeb_Build
   d. Select Stable build only.
   e. Enter Artifacts to copy:**/*

   f. Click Add build step again.
   g. Select Invoke top-level Maven targets.
   h. Select Maven version: MAVEN_HOME.
   i. Enter Goals:
      package

4. Under Post-build Actions:
   a. Click Add post-build action.
   b. Select Archive the artifacts.
   c. Enter Files to archive:**/*

   d. Click Add post-build action again.
   e. Select Build other projects.
   f. Enter Projects to build:
      MavenWeb_Deploy
   g. Select Trigger only if build is stable.

5. Click Apply.
6. Click Save.

STEP 6: CREATE MAVENWEB_DEPLOY
-------------------------------
1. Return to the Jenkins Dashboard.
2. Click New Item.
3. Enter: MavenWeb_Deploy
4. Select Freestyle project.
5. Click OK.

CONFIGURE MAVENWEB_DEPLOY
~~~~~~~~~~~~~~~~~~~~~~~~~~
1. In the Description field, enter:
   Web Code Deployment

2. Under Build Environment:
   a. Select Delete workspace before build starts.

3. Under Build Steps:
   a. Click Add build step.
   b. Select Copy artifacts from another project.
   c. Enter Project name:
      MavenWeb_Test
   d. Select Stable build only.
   e. Enter Artifacts to copy:**/*

4. Under Post-build Actions:
   a. Click Add post-build action.
   b. Select Deploy war/ear to a container.
   c. Enter WAR/EAR files:
      **/*.war
   d. Enter Context path:
      webpath
   e. Under Containers, select:
      Tomcat 9.x Remote
   f. Select or add the Jenkins credentials for the Tomcat Manager user.
   g. Enter the Tomcat URL:
      http://localhost:8085

5. Click Apply.
6. Click Save.

STEP 7: CREATE THE BUILD PIPELINE VIEW
--------------------------------------
1. Return to the Jenkins Dashboard.
2. Click the + sign beside the existing views (usually beside All).
3. Enter the view name:
   MavenWeb_Pipeline
4. Select Build Pipeline View.
5. Click OK or Create.
6. Under Layout, select:
   Based on upstream/downstream relationship
7. Under Initial Job, select:
   MavenWeb_Build
8. Click Apply.
9. Click Save.

STEP 8: RUN THE PIPELINE
------------------------
1. Open MavenWeb_Build.
2. Click Build Now.
3. Open the build number.
4. Click Console Output.
5. Wait for MavenWeb_Test to be triggered.
6. Open MavenWeb_Test.
7. Open its build number.
8. Click Console Output.
9. Wait for MavenWeb_Deploy to be triggered.
10. Open MavenWeb_Deploy.
11. Open its build number.
12. Click Console Output.
13. Open the MavenWeb_Pipeline view.

STEP 9: VERIFY THE WEB APPLICATION IN TOMCAT
--------------------------------------------
1. Open the Tomcat homepage in another browser tab:
   http://localhost:8085
2. Open the Tomcat Manager application.
3. Sign in using the Tomcat Manager credentials.
4. Find the deployed application with context path:
   /webpath
5. Click the /webpath link.
6. Verify that the web application page is displayed.

END
